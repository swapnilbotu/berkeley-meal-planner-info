Berkeley Meal Planner

A personal meal-planning application maintained by swapnilbotu. This independent project is not affiliated with or endorsed by the University of California, Berkeley.

The application retrieves official Berkeley Dining menus and nutrition facts, selects lunch and dinner using the account owner's preferences, and creates or updates the two meal tasks in the owner's existing Google Tasks list.

Google authorization lets the application verify the intended account, check existing meal tasks to avoid duplicates, and maintain meal descriptions and due dates. It runs as a scheduled Python application in a private GitHub repository. This public website contains information only; it does not sign visitors in or access their tasks.

This is a personal-use application, not a public signup service.
