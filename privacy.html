Berkeley Meal Planner

Privacy policy

Effective October 22, 2026. This policy describes the personal Berkeley Meal Planner application maintained by swapnilbotu.

Data accessed and purpose

With the account owner's consent, the application accesses verified Google account email information, Google Tasks list identifiers and titles, and task identifiers, titles, notes, due dates, and completion status in the configured list and requested date ranges. It uses this information to verify the account, avoid duplicate meal tasks, consider recent meals, and create or update lunch and dinner tasks. It may remove duplicate meal tasks previously marked as managed by this application. Unrelated tasks are not intentionally modified.

The requested permissions are OpenID account identification, email identification, and Google Tasks read/write access. Google Tasks permissions technically allow creating, editing, organizing, and deleting tasks; the application's code limits its actions to its meal-planning purpose.

Storage and service providers

Meal tasks remain in the owner's Google account. The OAuth client credentials and refresh token are stored as encrypted GitHub Actions secrets in the private application repository. Access tokens and retrieved task data are processed on the workflow runner. Generated plans are temporary runner files; execution logs and job summaries may retain meal details under the private repository's retention settings. Credentials are not intentionally printed in logs or committed to source control.

Google processes authorization and task requests; GitHub provides private workflow execution, secret storage, logs, and this public documentation site. Google account data is not sent to Berkeley Dining. This public site contains no private meal plan or OAuth credentials.

Use and sharing

Google user data is used only to operate the owner's meal-planning integration. It is not sold, used for advertising, or used to train AI models. The application uses no AI inference service. Berkeley Meal Planner's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Control, retention, and deletion

The owner can stop scheduled execution in GitHub Actions and revoke the application's access in Google Account connections. Revoking access does not delete existing meal tasks. The owner can delete tasks in Google Tasks, remove the three OAuth secrets from GitHub, and delete workflow runs and logs in GitHub. Secrets remain until removed; task and log retention follows the owner's Google and GitHub settings. Any downloaded OAuth client JSON should also be removed when no longer needed.

Website visitors and contact

This site adds no analytics, advertising, forms, or tracking scripts. GitHub Pages may process ordinary connection information to serve the site under GitHub's privacy statement.

Contact the maintainer (do not post credentials or private task information).
